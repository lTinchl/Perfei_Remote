# Perfei_Remote
## 简介

此项目根据B站开源大佬Fei_行家所发布的Remote_V3.0代码的基础移植了 [[bdth-7777777]](https://github.com/bdth-7777777)大佬的[OLED_UI](https://github.com/bdth-7777777/OLED_UI)并优化了nrf发收包与无人机电压获取。

## 如何使用
1. 通过Code下载压缩包解压使用
2. 使用git clone部署至本地。
